# Longhorn eVTOL KiCad library

Shared symbols, footprints, and 3D models for every club board. Rules for adding parts are in [`docs/hardware/pcb-design-guide.md`](../docs/hardware/pcb-design-guide.md#library-rules).

| Path | Contents |
| --- | --- |
| `longhorn.kicad_sym` | Symbols (created with the first custom part) |
| `longhorn.pretty/` | Footprints |
| `3d/` | STEP models |

Every symbol needs Manufacturer, MPN, and DigiKey fields. Every new footprint is checked against its datasheet by a second person before use.
